# Выводы

- NotebookEdit insert добавляет ячейки в начало — нужно либо использовать cell_id для позиционирования, либо переупорядочить скриптом после
- При создании больших ноутбуков (40+ ячеек) эффективнее написать весь JSON через Write одним файлом для первой порции, затем добавлять остальное
- Regex для auto-discovery лучше хардкода: новые эксперименты подхватываются автоматически
- Передача путей как параметров (buy_path, sell_path) вместо конструирования из глобалов делает функции более тестируемыми
